Cloud translation

On-device translation keeps every message on this machine. Turning this on sends message text to DeepL, a company outside this browser — including messages other people wrote. They have not agreed to that, and you cannot agree on their behalf. It is off by default for that reason. Turning it back off stops it immediately.

What gets sent, and when:

  • Only messages in a language this device cannot translate locally. When a language pack is available it is always used first, and nothing leaves the machine. A pack that is merely downloadable never becomes a cloud request — you are asked to download it instead.
  • Only in channels. Direct messages are excluded unless you separately tick the box below.
  • When you press translate properly on a message, the few messages before it are sent as well, as context. Text only — no names, no timestamps, no attachments. That button does nothing while this setting is off.

Anything translated in the cloud is marked cloud in the layer under the message, so you can always tell which ones left.

A group channel is a room you are already sharing. A DM is usually two people, so it is gated separately rather than coming along with the tick above.

Sending messages

Ctrl/Cmd + Shift + T translates what you've typed and shows it for review. It is put in the message box, never sent — you press Enter yourself.

Recommended. A back-translation check can't catch a wrong translation that reads well, but anyone bilingual in the channel sees both lines and can correct it.
