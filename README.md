# Polyglot

In-place translation for multilingual group chats — read Discord in your
language without leaving the conversation, with a Telegram bot to follow.

Translations render *underneath* the original message, never replacing it.
On-device translation by default (free, private, no message content leaves the
machine); cloud engines opt-in with your own API keys; LLM translation only
when you ask for it per message.

**Status:** planning, v2. See [docs/PLAN.md](docs/PLAN.md) — scope, verified
capability findings, architecture, phases gated on translation quality, and an
honest account of the privacy and maintenance costs.
