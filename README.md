# Polyglot

In-place translation for multilingual group chats — read Discord, Telegram,
WhatsApp and Slack in your language without leaving the conversation.

Translations render *underneath* the original message, never replacing it.
On-device translation by default (free, private); cloud engines opt-in with
your own API keys.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md) for the full build plan —
scope, architecture, phases, and the hard parts.
